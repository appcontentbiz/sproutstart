# SproutStart Image Assets

This directory contains high-quality images focused on beginner farmers and gardeners.

## Image Categories

1. Hero Images
- beginner-farmer.jpg - Friendly farmer teaching basics to newcomers
- learning-basics.jpg - Hands-on learning in a small garden
- community.jpg - Community garden gathering
- garden-planning.jpg - Simple garden planning session
- local-store.jpg - Welcoming garden center

2. Learning Section Images
- basic-tools.jpg - Essential farming tools for beginners
- first-garden.jpg - Simple backyard garden setup
- soil-basics.jpg - Learning about soil composition
- seed-starting.jpg - Starting seeds indoors

3. Community Images
- mentor-session.jpg - Experienced farmer mentoring beginners
- group-learning.jpg - Community workshop
- farmers-market.jpg - Local farmers market
- success-story.jpg - New farmer's success

## Image Requirements

- Welcoming and approachable atmosphere
- Focus on small-scale and beginner-friendly activities
- Clear, well-lit, and easy to understand
- Diverse representation of new farmers
- Emphasis on learning and community support

## Image Sources

Images can be obtained from:
1. Licensed stock photo services
2. Community submissions (with permission)
3. Educational institutions
4. Local farming organizations

## Usage Guidelines

1. Maintain welcoming and encouraging tone
2. Show achievable farming goals
3. Include proper attribution
4. Optimize for web performance
5. Include descriptive alt text
